# `npx koustav`

A small terminal portfolio introduction for Koustav Roy. It prints a concise profile, strengths, stack, proof points, and contact links in a terminal-friendly format.

## Test locally

```bash
node index.js
```

## Publish

The package is prepared with the public package name `koustav` and version `2.0.0`. Before publishing, confirm that the npm account being used owns the package name and run:

```bash
npm login
npm publish --access public
```

After publication, visitors can run:

```bash
npx koustav
```

The portfolio website's copy button already copies this command. The existing package name `koustav` is currently registered on npm, so publishing requires access to that npm package or choosing another available package name.
