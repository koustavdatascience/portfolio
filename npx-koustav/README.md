# `npx koustav-roy`

A small terminal portfolio introduction for Koustav Roy. It prints a concise profile, strengths, stack, proof points, and contact links in a terminal-friendly format.

## Test locally

```bash
node index.js
```

## Publish

The package is prepared with the public package name `koustav-roy` and version `2.0.0`. Before publishing, log in to the npm account you want to use:

```bash
npm login
npm publish --access public
```

After publication, visitors can run:

```bash
npx koustav-roy
```

The portfolio website's copy button copies this command automatically.
